## 一、用户最终决定（总纲）

1. **外壳用交接包（PHOEN_ORIGINAL_HANDOFF_2026-08-25）的玻璃终端外观，内核细节完全按 `PLAN.md`。**
   - 即：`mobile-ui-v3.js + voice-console.css`（玻璃栈）负责视觉与交互外壳；
   - 数据契约、APP 结构、六引擎、提示词工作流、正文标签等一律以 PLAN 为准。
2. **不移植参考代码**：所有改动围绕本项目自主实现；交接包资产作为素材直接采用，不做"逐行移植"。
3. **Dock 保留主页图标**（用户口头修改，覆盖 PLAN 原文）：五图标 = 主页、QQ、电话、绘画、设置。
4. **扩展身份**：display_name「Phonie 手机」，版本 1.0.0，命名空间 `phonie_v2`；旧 `phonie` 数据不读取、不迁移、不删除。
5. **引擎范围**：只保留 IndexTTS2 / GPT-SoVITS / VoxCPM2 / Edge TTS / ElevenLabs / MiniMax 六引擎；**删除豆包 TTS**；IndexTTS2 只保留 JSON HTTP 接口（删 Gradio）；MiniMax 只走服务插件 `/api/plugins/tts-minimax-resources`（删浏览器明文直连）。
6. **消息类型**：文字、图片、转账、语音、表情包、引用、撤回；**删除红包**（原"红包"全部改名为"表情包"）、删除音频下载等未要求功能。
7. **正文标签**：`「{译文}」[TTS:{角色}:{情绪}:{文本}]`，解析器只以前三个冒号做字段分隔；渲染后删除控制标签、保留可见译文并插入播放控件。
8. **UI 文案**只写直接的状态、原因与下一步，不加入玩笑、无关括号、虚构限制（如"（无东坡肉）"）。

2. **主动来电触发链**：接入旧 `app.js` 已有实现——QQ 回复后分析 `proactiveCall` 意图、联系人独立冷却守卫、生成/合成/通话中不触发、先准备（灵动岛 preparing_call）再响铃；30 秒未接记未接。

5. **Dock 行为**：进 APP 后 Dock 消失、只留左上角返回与 Home Indicator（保留主页图标不变）。
6. **灵动岛点击**：跳回正在运行的 QQ / 绘图 / 通话页面。
7. **显示入口**：设置·显示子页增加入口开关（悬浮球 / 魔棒菜单 / 两者）。
8. **主题自定义进阶**：本地壁纸上传压缩入库、八个 APP 图标自定义与逐项恢复默认。
9. **多人电话 15–28 段校验**、打字延迟公式按 PLAN 参数核对。
10. **测试契约**：为玻璃栈新增 1.0 契约测试（现有 37 项保留）。
